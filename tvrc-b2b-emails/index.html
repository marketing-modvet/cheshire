Usage & production notes

  • Personalization tokens: {{first_name}}, {{clinic_name}}, {{sender_name}}, {{sender_role}}, {{unsubscribe_url}} — swap syntax to match the sending platform (Klaviyo / Outlook mail-merge / manual).
  • Build: 600px table-based layout, inline CSS, bulletproof buttons — safe for Outlook, Gmail, Apple Mail. Logo is hot-linked from tvrc.ae; for production, host on the ESP's CDN.
  • Brand (per official TVRC Brand Guidelines PDF): Montserrat typography; main colors turquoise #14aecb + blue #4692cf + white; secondary navy #0f3d64, coral #ef827f, light blue #d7edfc; medical-cross brand element used as section marker; logo left-aligned per guidelines. Consistent header/hero/footer across all three so the set reads as one system.
  • Image & portrait placeholders: dashed light-blue zones marked “Image will be here” / “Portrait will be here” (with suggested dimensions) — no doctor photos exposed; designer drops in approved photography before send.
  • Key message discipline: every template repeats the collaboration promise (referring vet stays central; TVRC never competes for the client) — the #1 objection killer in referral-centre outreach.
  • No prices in-email per the brief — lab CTA requests the price list & sample submission requirements instead.
