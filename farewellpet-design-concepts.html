2. Card / tile styles

How service tiers, steps, or feature blocks could look — used throughout the website and one-pager.

Style 1

Soft cream fill, subtle coral accent dot. Calm, low-contrast — good for dense grids.

Style 2

White fill, coral border + shadow. Higher contrast, good for a single "featured" tier.

Style 3

Solid coral fill. Strongest visual weight — best used sparingly, one card max per row.

Currently the website mixes Style 1 (default cards) with Style 2 (the "Most chosen" featured pricing tier) — Style 3 is included here as an option but not yet used anywhere, since a full coral card repeats the same contrast risk as Hero A if text isn't set to white explicitly every time.
