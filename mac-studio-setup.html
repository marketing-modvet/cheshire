🔧Setup Manual — Step by Step
Follow top to bottom. Reference build: OpenClaw 2026.6.6 · Node v22.22.2 · macOS.

  1. STEP 0 — macOS base

    • Boot Mac Studio, sign in with Apple ID, finish setup wizard.
    • Run all macOS updates: System Settings → General → Software Update.
    • Create/confirm a dedicated admin user that will run OpenClaw.
    • Plug in Ethernet. Set a DHCP reservation on the router if possible.

  2. STEP 1 — Server mode (act like a server, not a laptop)

    System Settings → Energy:

    • "Prevent automatic sleeping when the display is off" → ON
    • "Start up automatically after a power failure" → ON
    • Recommended: enable Auto-login for the run user (survives reboots)
    • FileVault: your call — ON = secure, but blocks unattended auto-boot

  3. STEP 2 — Remote access: SSH + Tailscale

    • Enable SSH: System Settings → General → Sharing → Remote Login = ON
    • Install Tailscale: 
      brew install --cask tailscale
      Or download from tailscale.com
    • Create a new Tailscale account at tailscale.com — new tailnet for this location (separate from home).
    • Sign in on Mac Studio. Then install Tailscale on your phone + PC and join the same new tailnet.
    • Verify: 
      tailscale status
      Should show Mac Studio + your devices listed.
    • Note the Mac Studio's 100.x.x.x / MagicDNS name — used for web UI access

  4. STEP 3 — Syncthing (file sync PC ↔ Mac Studio)

    brew install syncthing
syncthing serve --no-browser
    • GUI at http://127.0.0.1:8384 (or via Tailscale from PC)
    • Add Andrew's PC device ID and/or cheshire-server as a remote device; accept on both ends
    • Share working folder(s) — confirm a test file syncs both ways
    cheshire-server Syncthing device ID:
    RDDAT47-BC63R66-XMC35EN-45256BA-6ANZZEK-6QET7W2-J46FQR5-DWZMOAP

  5. STEP 4 — Install Homebrew + Node + OpenClaw

    # Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Node 22+ (match reference v22.22.2)
brew install node
node --version    # expect v22.x

# OpenClaw (global)
npm install -g openclaw
openclaw --version

# Optional: Python (for utility/deploy scripts)
brew install python

  6. STEP 5 — First run / config

    openclaw

    Run the wizard, or edit ~/.openclaw/openclaw.json directly (see skeleton below):

    • Default model: anthropic/claude-sonnet-4-6
    • Image model: openai/gpt-image-2
    • Provide Anthropic + OpenAI API keys during setup

  7. STEP 6 — Telegram surface

    • Telegram → @BotFather → /newbot → get the bot token
    • Your Telegram user ID (allow-list): 779214693
    • Add to OpenClaw config: Telegram channel with bot token + allow-list (see skeleton)
    • Restart OpenClaw → message the bot → confirm reply

  8. STEP 7 — Web UI (via Tailscale)

    • Find OpenClaw's port (check config or startup output — default varies)
    • From PC/phone on the tailnet, browse to:
      http://<mac-studio-tailscale-name>:<port>
    • No domain, no Cloudflare — private over Tailscale only
    Du has no static IP — Tailscale handles this perfectly. Server wired, client on Wi-Fi/cellular = works regardless.

  9. STEP 8 — Persistence + verify everything

    • Confirm OpenClaw auto-starts on reboot (launchd / pm2 / login item)
